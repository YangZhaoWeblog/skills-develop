# 术语表（glossary）

> 业务领域名词的统一定义。所有 AI 与人共用——避免"同名异义"和"异名同义"。

## 定义格式

```
### {术语}（英文 / 缩写）

- **定义**：[一句话精确定义]
- **同义词 / 别名**：[业内常见的其他叫法，标注是否在本项目避用]
- **反义 / 易混**：[容易搞混的相邻概念]
- **示例**：[一个最小例子]
```

## 触发记录的场景

- AI 第一次用某业务名词时（命名歧义会贯穿整个项目）
- 代码 review 中发现命名不一致
- 新人 onboarding 提问
