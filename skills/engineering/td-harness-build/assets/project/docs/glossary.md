> **用途**：明确理解本项目所需的概念、缩写和易混含义；每个 Harness 保留本文件，没有待记录条目时注明“暂无”。

**收录标准**：理解项目必须知道，或在本项目中容易误解的词。标准术语需要时引用权威定义并说明项目用法，不抄百科，也不要求词必须由项目发明。

定义来自已确认需求、项目文档或实际代码；有冲突或含义未定时标“待确认”，不能凭名称猜测。标准概念的项目限制须单独说明，不能悄悄改写标准含义。
