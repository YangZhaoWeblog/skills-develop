# 接口与字段变更历史

当前接口契约以实际 Proto、IDL、OpenAPI 或路由定义及其注释为准。本文记录变更过程，供问题排查与历史回顾，不作为当前字段说明的副本。

## 记录规则

- 字段新增、删除、改名、类型 / 编号 / 必填性 / 默认值 / 业务语义变化时追加记录；接口行为变化也可记录。
- 按下表记录变更前后及影响；Proto 字段附编号。接口级变化填写方法或路由，字段列写“不涉及”。
- 依据使用 Git commit、MR、需求链接或可定位源码；未确认的信息写“待核对”，不猜日期、原因或旧行为。
- 保留已有历史。迁移旧文档时原样保留变更内容与出处，不强行把综合记录拆成未经验证的字段结论；更正旧记录时注明更正原因和依据。
- 修改接口时先更新契约与注释，再同步索引和本表；仅文案整理且没有契约 / 语义变化时无需新增历史。
