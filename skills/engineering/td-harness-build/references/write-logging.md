# 日志规范生成指导

> 填写 **.harness/docs/logging.md** 时读取。

从实际依赖、日志调用、初始化配置及运行说明核对日志库、等级、格式、关联字段、采集入口和保留策略。只填有证据的内容；没有日志机制时如实注明，已有项目内容保留。

按模板维护一份日志规范。**release.md** 只引用它；日志参数以真实配置为准，不再抄一张参数表。动态调级只描述已有能力，不要求新增。

已有重复说明先融合独有内容、修复引用，再按 **[upgrade-project.md](upgrade-project.md)** 处理旧段落。保留敏感数据保护和排障所需证据，避免多个调用层重复打印同一错误。
