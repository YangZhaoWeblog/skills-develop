# AGENTS 生成与审查

> **独立初始化 Agent 指令**：执行前读取 [派发约定](init-agents.md#2-派发约定)，按主 Agent 指定的输入、文件范围和授权处理本专题。

> 生成或融合项目 AGENTS 时读取。模板为 `assets/agents.md`，修改边界见 [upgrade-project.md](upgrade-project.md)。

## 1. 保留结构与规则

`build_harness.sh` 在入口缺失时复制模板，已有入口则更新第二章 **Workflow**，保留其余章节。运行前完整读取原入口，将 Workflow 中的项目独有规则按归属保留到 **Rules**；冲突先解决。章界不明确或入口为软链时，脚本保留原文并提示 **[MERGE]**；用 **cp** 复制 **assets/agents.md** 为候选，再融合项目内容。只有只读权限时返回候选，由主 Agent 应用。

**Workflow 保留模板原文**，不概括重写。项目事实填写 **Index、Commands、Structure、Rules**；已批准的项目差异在 Rules 集中说明，未解决的流程冲突交用户决定。融合后按 Skill 工作流重跑构建脚本，再比较差异。

用 **diff -u** 比较模板与候选、原入口与候选。逐项确认新增事实、保留规则和已批准差异后再应用；退出码 **1** 表示有差异，**大于 1** 才是比较出错。

## 2. 按证据填充

AGENTS.md 负责项目规则、稳定约束和跨任务导航，不承载具体任务链接、当前进度、审批结论、修复经过或验证结果。

| 位置 | 内容与依据 |
|---|---|
| 顶部项目 / Stack | 一句话用途及主要语言、框架；读取 README、已有入口及依赖配置 |
| Commands | 模块或包名、启动入口及构建、测试、生成命令；引用详细规范，缺失明确标记 |
| Structure | 关键目录职责、分层方向、生成代码边界；读取目录和调用关系 |
| Rules | 保留项目命名、数据访问、契约、迁移、注释、错误处理及保护分支等适用约束 |
| 主题索引 | 按下方必做步骤核对主题、实际文件和读取时机 |

仓库类型仅在影响操作时写入 Structure，例如多项目目录与工作目录。AI 有特殊职责时写入 Rules；“高级开发工程师”等通用角色不写。详细版本维护在项目配置和环境规范，必要的版本约束保留在 Rules。

模板骨架必须保留，必填事实未知时标明待定或不涉及，不编造内容。可选信息无实际作用时省略。项目语言不限于 Go；按真实技术栈采集。

### 主题索引填充（必做）

1. 用 `rg --files --hidden` 定位项目文档、契约和工具配置；读取已有索引，保留跨任务有效的项目入口。具体产品、开发及历史任务的 Overview、阶段文件不进入 Index，无论链接是否可达；已有此类条目只移除索引行，保留任务原文件。任务定位沿用 Workflow §2.5，不另建“当前任务”入口或登记表。
2. 逐行核对模板主题，替换为项目实际路径。接口契约补实际 proto / IDL / OpenAPI / 路由入口；数据库和运维文档按项目位置填写，不照抄示例路径。
3. 核对项目已有的 hook、CI、工作流门禁、Harness 治理和测试专属规则。存在时补对应主题及真实文件或配置入口；规则权威与冲突处理留在专题规范，不塞进索引。
4. 检查每个入口是否存在、主题是否覆盖。不存在且不适用的条目移除；必要资料缺失时标明“待补齐”并报告，不能写成可用链接。不得仅为凑齐索引创建治理文件。

索引固定为“何时读取、主题、文件”三列。主题全部加粗，“何时读取”使用普通文本。每个主题有明确入口；低频子文档由主题索引链接。实际路径核对完成前，不能把模板复制报告为索引接入完成。

## 3. 核对

- 对照旧入口逐条核对项目规则，独有内容已合并或列明冲突；不能以模板缺项为由丢弃。
- 实现授权、任务隔离、测试先行、真实证据及 Git 边界完整。
- 产品和开发的 Clarify 分工、AC 来源、AT 设计及执行位置一致。
- 主题索引逐项核对完成，实际契约、项目配置和专属规范入口已补齐；具体任务链接已排除，缺口明确报告。
- 文件及章节引用可达，尤其是阶段模板引用的 **AGENTS.md §2.6**、**Plan §6.1–6.4**；CI 或 hook 强制执行须有实际配置证明。
- Agent 分工入口指向 **.harness/agent-roles.md**，本阶段核对链接与职责位置；四角色配置和实际调用由后续 **agent-setup.md** 接入，未核验前不能写“已安装”。
- 保留 **§2.1** 的主 Agent 身份定义及 **§2.3「反馈与返工」**；核对角色权限、常见返回位置与复验／复审闭环，不把去向表改成固定退步规则。
- 主入口保持简短；详细说明通过专题引用提供，职责和硬约束不得为凑行数而删除。

交付前在隔离目录按候选入口创建一次开发任务：核对 **00–07** 文件齐全、章节与表格保留、后续阶段未标完成；已有目录重试不能覆盖内容。报告实际结果与差异，再由主 Agent 核对接入是否完成。
