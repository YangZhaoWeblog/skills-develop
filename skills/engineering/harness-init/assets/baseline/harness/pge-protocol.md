## Activation

Activate this file when the project has medium/large work, critical flows, batch work, or explicit planner/generator/evaluator separation.

## Default Shape

- Define goal, scope, non-goals, acceptance criteria, implementation order, verification, fallback, and circuit breaker.
- Separate planning, implementation, and evaluation when possible.
- Return to the main workflow for Verify and Close.

## Circuit Breaker

If the same interface or flow fails 3 rounds, stop implementation and return to design or clarification.
